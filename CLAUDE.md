Chat updates are authenticated polling (no Supabase Realtime). Report: `docs/RAILWAY_NEON_MIGRATION_REPORT.md` (local only).

**State:** Enigma runs on Railway (project `blissful-solace`, environment `production`; services `Enigma` web, `enigma-api`, `Postgres` (stopped)), built from GitHub `stokastisk-ai/enigma` `main` with the Dockerfiles in `apps/web` and `apps/api` (repo-root build context).
